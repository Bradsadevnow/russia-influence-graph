# Citation audit — READ BEFORE ANYTHING SHIPS

The project's entire credibility rests on every edge tracing to a real primary
source. Journalistic synthesis is fine for orientation, but each edge that appears
in the report or the website must be verified against the actual document it
claims. This file tracks that verification.
